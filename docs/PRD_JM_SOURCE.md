## 1. 背景与目标

Nowen Reader 目前的内容全部来自本地书库(扫描磁盘文件入库)。JMComic-qt 提供了一套独立的 REST 服务,封装了 JM 漫画上游的浏览、搜索、阅读、收藏、评论等能力,并自带图片乱序还原代理。

**本需求目标**:在 Nowen Reader 前端新增「在线漫画源」板块,复用 JMComic-qt 服务的能力,让用户在不离开 Nowen Reader 的情况下完成 JM 源的「连接 → 登录 → 浏览 → 阅读 → 收藏/历史」完整闭环。

**明确不做**:

- 不将 JM 源内容写入本地书库/数据库,不参与本地搜索、统计、合集、刮削;
- 不改动 Nowen Reader 后端(Go)数据模型;在线源为纯前端板块直连 JM 服务(其 CORS 已全开放);
- 不做 JM 账号注册、充值等增值操作,仅覆盖浏览与阅读必需能力。

## 2. 名词与前提

| 名词 | 说明 |
|---|---|
| **在线源服务(JM 服务)** | JMComic-qt 的 mobile/server 实例,用户自行部署于本机或 NAS,默认 `http://<host>:8964` |
| **上游** | JM 服务背后的 JM 官方接口。Live 模式下**必须经代理访问**,否则全部内容接口不可用(返回 2002 网络错误) |
| **Mock 模式** | JM 服务以 `JM_MOCK=1` 启动,全部端点返回确定性假数据、零上游请求,用于开发与联调 |
| **Live 模式** | 真实模式,经 jmcomic SDK 对接上游 |
| **aid / pid** | JM 漫画 id / 章节(阅读单元)id,在线源内容的唯一标识 |

**部署前提(约束)**:

1. JM 服务由用户单独部署并保证可达;Nowen Reader 前端与 JM 服务跨源访问(CORS 已放开),Bearer 鉴权无 Cookie 依赖。
2. 若 Nowen Reader 以 HTTPS 提供,JM 服务也必须以 HTTPS 或经同域反向代理提供,否则浏览器混合内容策略会拦截请求。
3. Live 模式下,JM 服务所在机器必须能通过代理访问上游;代理默认值 `http://127.0.0.1:10809`。

## 4. 功能需求

### M1 设置 · 在线漫画源(含代理设置)⭐ 本需求核心前置

设置页新增「在线漫画源」页签,包含以下配置块:

**① 连接配置**

- **服务地址**:JM 服务的 Base URL(如 `http://192.168.1.10:8964`);保存前先探测再落库,探测失败提示并**自动回滚**为原地址(对齐 JM 官方 Web 行为)。
- **连接测试**:手动触发 #1,展示服务状态、当前模式(Mock/Live 徽标)、版本与 upstream SDK 版本。

**② 代理设置(上游代理)⭐**

- 输入框,占位提示默认值 `http://127.0.0.1:10809`;支持清除(空 = 直连)。
- 保存动作:调用 **#28 PUT /api/settings** 写入 `proxy`,**即时生效于 JM 服务**(已登录会话保持登录态,由服务端保证)。
- 保存成功后回调 **#1** 做连通性反馈;提示文案需说明:health 仅代表 JM 服务本身可达,**不代表代理到上游可达**(上游连通性以实际浏览为准)。
- 说明文案:Live 模式下不配置代理将无法访问任何上游内容(内容接口返回 2002),Mock 模式不受影响。
- 读取当前值:**#27 GET /api/settings**(同时取回 `imageQuality` 与 `mock` 标识)。

**③ 内容画质**

- 三档:高 / 中 / 低(对应服务端 JPEG 质量 90/75/60);经 **#28** 写入 `imageQuality`;切换后新加载图片生效(服务端缓存键含画质,旧画质缓存不会误命中)。

**④ 维护操作**

- **清空阅读历史**:调用 **#26 DELETE /api/history**,需二次确认;清空的是 JM 服务端历史(与 Nowen Reader 本地历史无关,文案需明确)。
- **退出登录**:调用 **#5**,清除本机会话(见 M2)。

### M2 在线源登录

- 独立登录页(板块内未登录时全量重定向至此),包含:JM 账号用户名、密码、验证码。
- **验证码**:默认不显示;登录返回 `code=1003`(data.captchaRequired)时显示并加载 **#2**(直接作为 `<img src>`,加时间戳防缓存),点击图片刷新;其他失败若验证码已展示也自动换一张。
- 登录成功(**#3**):保存返回的 token 与用户信息,跳转在线首页;展示 `userInfo` 摘要(用户名、等级、VIP、收藏数/上限等)。
- **登录态特征(需向用户透出)**:token 有效期 7 天;**JM 服务重启即全部失效**。失效后由全局 401 处理接手(§4.12)。
- 退出:设置页(M1④)与登录页均可发起 **#5**。

### M3 在线首页(发现)

三个内容标签 + 可选第四标签:

| 标签 | 接口 | 说明 |
|---|---|---|
| 推荐 | **#8 promote** | 渲染服务端下发的区块列表;首个区块固定为「连载更新」入口(跳连载表),其余静态区块横向卡片流 |
| 最新 | **#9 latest** | 分页滚动加载;注意上游无 total,「满页即认为还有下一页」,允许出现一次空页后终止 |
| 连载表 | **#10 serialization** | 按星期(1–7)与类型(全部/漫画/韩漫)筛选,分页加载 |
| 全部(可选) | **#7 comics/index** | Latest/View 两种排序的列表 |

卡片展示 `ComicItem` 字段:封面(服务端已代理)、标题、作者、分类、 likes/views、更新日期。

### M4 分类浏览(可选,最后实施)

- 数据源 **#6 categories**(两层分类树);选中子分类后进入 **#13 search** 的 `mainCategory` 模式浏览。

### M5 搜索

- **#13 search**,支持:
  - 关键字模式:`keyword` + `searchType`(全站/作品/作者/标签/角色)+ 年份/月份过滤;
  - 分类/排行模式:无关键字时按 `mainCategory` + `sort` 浏览;
  - 排序:最新 / 最多点击 / 月·周·日排行 / 最多图片 / 最多爱心。
- **产品规则(上游怪癖,需如实遵循)**:
  - 日排行(`mv_t`)带分类时上游返回空,UI 需给出「该排行不支持分类筛选」的提示或自动取消分类;
  - 结果 total 封顶 10000、页码封顶 120,滚动到底给出「仅展示前 120 页」提示;
  - 空关键词 + 排序浏览不携带关键字(由接口路由规则保证,前端无需特殊处理,仅验收关注)。

### M6 每周必看

- **#11 week** 获取期数列表(新→旧),选择期数与类型(漫画/韩漫/其他)后 **#12 week/filter** 展示单期列表(无翻页)。

### M7 漫画详情

- **#14 GET /api/comics/{aid}**:封面、标题、作者、简介(纯文本)、标签、likes/views、更新时间、章节列表(`episodes`,单章漫画也有一个默认章)。
- **互动区**:
  - 点赞:**#19**,展示当前 `liked` 状态;**上游为切换语义,结果以响应 `liked` 为准**;`liked=null` 时回查详情刷新状态;
  - 收藏/取消:**#22 / #23**,同样为切换语义,以响应 `favorited` 为准,状态不明时回查详情;
  - 评论:**#17** 分页列表(楼中楼 `replies`、`replyTo`),**#18** 发布评论;评论区需登录(未登录时入口引导去 M2),内容按纯文本渲染(服务端已剥 HTML)。
- **继续阅读**:进入详情时用 **#24** 查询该漫画最近进度(按 aid 匹配),命中则章节列表定位到对应 `pid` 与页码,提供「继续阅读」主按钮。

### M8 在线阅读器(沿用现有阅读器体验)

> **产品决策(评审变更)**:在线阅读区**沿用 Nowen Reader 现有阅读器的视图层体验**(阅读模式/翻页交互/预加载/滤镜/工具栏/设置面板均与本地阅读器一致),通过其可复用的视图组件挂载 JM 数据,**不复制一套新阅读器**。
> **硬性约束:不得修改现有阅读器任何代码与行为**;JM 特化逻辑(数据获取、图片 URL、进度上报、章节衔接)只存在于新的 JM 阅读器页面壳中。

- 数据:**#15 GET /api/photos/{pid}** 获取章节图片清单(`images[].path` + `scramble` + 章节导航 `hasNext/nextPid`)。
- **图片**:逐张经 **#16 GET /api/image?path&scramble&aid** 加载(服务端完成乱序还原与缓存),前端不直接访问上游图片域名。
- **体验沿用**:阅读模式(单页/双页/条漫)、阅读方向、适应方式、预加载数、图片滤镜、工具栏与设置面板与本地阅读器共用同一套偏好与组件;`comicId` 类本地后端联动能力(预热等)不启用。
- **进度上报**:**#25 POST /api/history**,阅读中防抖上报(约 1.2s 合并),进入章节立即上报一次;字段 `aid/title/coverUrl/pid/epTitle/imageIndex`(1 基页码)。
- **章节衔接**:章节末尾/翻页越界时进入下一章(`nextPid`),替换当前历史避免堆栈堆积;详情页「继续阅读」通过 `?page=` 定位初始页码。

### M9 我的收藏

- **#20 favorites/folders**:收藏夹列表(名称 + 数量);
- **#21 favorites**:按收藏夹分页浏览(folderId 默认 "0";Live 语义为"全部收藏夹",Mock 为"默认夹",前端透传即可);
- 列表项支持取消收藏(**#23**),与 M7 详情页收藏状态联动(操作后回查)。

### M10 阅读历史(源内)

- **#24 GET /api/history**:按更新时间倒序分页展示(封面 + 标题 + 章节名 + 页码),点击直达阅读器并定位页码;
- **#26** 清空入口(与 M1④ 同一能力)。
- 注意:此历史是 **JM 服务端数据**(设备级共享、不按账号隔离),与 Nowen Reader 本地「阅读历史」页完全独立,入口与命名需做区分(如「在线·历史」)。

### M11 每日签到

- 入口:设置页(M1)与在线首页用户卡;
- **#29** 展示签到日历(本月 `days`、`todaySigned`)与签到按钮;**#30** 执行签到(服务端先查后签、幂等),展示返回 `msg`(成功/今日已签)。

### 4.12 全局会话与错误处理(跨模块)

- **401 / code=1002**:任一在线源接口命中 → 清除本地 JM 会话 → 轻提示「登录已失效」→ 引导至 M2 登录页;不弹重复提示。
- **错误码 → 用户提示**:1001 凭据错误;1003 出验证码;2001 上游错误(透出 upstream 摘要);**2002 网络/代理不可达 → 引导检查 M1 代理设置**;3001 资源不存在;4000 兜底。
- **422**(参数校验)按通用错误提示,不应在正常操作流中出现。
- 加载与空状态:所有列表有骨架屏与空态;在线源模块的全部请求可被用户中断(离开页面即取消),不做后台轮询。

## 5. 非功能需求

### 5.1 资源消耗约束(硬性)

- **开发/联调一律使用 Mock 模式**(`JM_MOCK=1`,零上游请求);Live 冒烟仅做单点验证(单页列表、单章图片、单次签到),**禁止**整站刷新、批量并发拉图、循环轮询。
- 列表一律按需分页加载(Live 单页 80 条,不一次性取多页);阅读器预加载默认 2 张、上限 3 张;图片依赖 JM 服务端 LRU 缓存(默认 500 张上限),前端不另建全量缓存。

### 5.2 内容敏感与隐私(硬性)

- 在线源内容默认按敏感内容处理:遵循 Nowen Reader 现有「隐私/敏感封面」显示策略(封面遮蔽),在在线源板块内同样生效。
- **截图规范**:开发验收、问题反馈、文档配图仅允许截取结构性界面(导航、设置表单、空状态、加载态);**不得出现封面墙、正文图片、评论内容等数据展示区域**;确需展示时必须打码。

### 5.3 安全

- JM token 仅保存在用户本机,不经过 Nowen Reader 后端;任何界面不回显密码。
- JM 服务返回的相对 URL(封面等)一律经 JM 服务的 `/api/image` 消费,前端不直接拼上游域名。
